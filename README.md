# Skyguard-CC
SkyGuard CC 是一个面向无人机遥感图像的开源 YOLO-OBB 检测平台，支持上传并选择多个已训练模型权重，对图像进行目标检测，生成并下载带旋转检测框的结果图。后续计划增加标签文件导出、热力图和特征图可视化功能，以支持科研结果展示。
